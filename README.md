# Flipper Zero App Catalog

A curated Flipper Zero app catalog featuring the best Flipper Zero apps, plugins, games, tools, and community resources. This repository combines the Official Flipper App Catalog with a community catalog to help users find the most useful Flipper Zero software in one place.

## Featured 123fzero Apps

- **[123DiceDnD](https://github.com/123fzero/123DiceDnD)** (Games) ⭐ 2: 123DiceDnD is a Flipper Zero D&D dice roller app with d4, d6, d8, d10, d12, and d20 support, multi-dice rolls, 3D animation, and Momentum firmware support.
- **[123PuffPacer](https://github.com/123fzero/123PuffPacer)** (Tools) ⭐ 2: Flipper Zero puff timer for IQOS, HEETS, TEREA, Lil Solid, glo, and Ploom. Pace heated tobacco sessions with vibration and sound alerts.
- **[123PeriodicTimer](https://github.com/123fzero/123PeriodicTimer)** (Tools) ⭐ 1: Flipper Zero repeating interval timer for recurring reminders, workouts, Pomodoro, breathing, and cooking.
- **[123Pomadoro](https://github.com/123fzero/123Pomadoro)** (Tools) ⭐ 1: Flipper Zero app by 123fzero
- **[123PomadoroClaude](https://github.com/123fzero/123PomadoroClaude)** (Tools) ⭐ 1: Flipper Zero app by 123fzero

Discover Flipper Zero apps, Flipper Zero plugins, Flipper Zero games, and practical Flipper Zero tools from both official and community sources.

`🏛️` = Official Flipper App Catalog, `💎` = Community Catalog (curated from awesome-flipperzero).
